
# PROJETO DE ESTRUTURA DE DADOS II

## Linguagens utilizadas
- Java
- Python

## 1. ALGORITMOS DE ORDENAÇÃO

Implementação de cinco algoritmos de ordenação:

- Bubble Sort
- Insertion Sort
- Selection Sort
- Merge Sort
- Quick Sort

### Funcionalidades
- Entrada manual de números;
- Geração automática de números;
- Leitura de números a partir de arquivo TXT (dados/numeros.txt);
- Escolha do algoritmo de ordenação;
- Exibição dos dados de entrada e saída;
- Exibição de até 100 elementos em grandes volumes de dados;
- Medição do tempo de execução;
- Comparação de desempenho entre os cinco algoritmos;
- Verificação se o vetor está ordenado;
- Simulações com entradas de tamanho n, n², n³ e n¹⁰, com registro dos tempos estimados.

## 2. TABELA HASH

Implementação de uma estrutura de dados do tipo Tabela Hash, utilizando encadeamento para tratar colisões.

A implementação deve seguir as orientações fornecidas pelo professor.
