PROJETO DE ESTRUTURA DE DADOS II - ALGORITMOS DE ORDENACAO

LINGUAGEM
Java.

ALGORITMOS IMPLEMENTADOS
- Bubble Sort
- Insertion Sort
- Selection Sort
- Merge Sort
- Quick Sort

FUNCIONALIDADES
- Entrada manual de numeros.
- Geracao automatica de numeros.
- Escolha do algoritmo de ordenacao.
- Exibicao dos dados antes e depois da ordenacao.
- Exibicao de no maximo os 100 primeiros valores.
- Medicao do tempo de execucao.
- Comparacao do tempo dos cinco algoritmos usando copias dos mesmos dados.
- Verificacao se o vetor ficou ordenado.

BIBLIOTECAS
O codigo nao possui comandos import e nao utiliza bibliotecas externas ou classes prontas de ordenacao. Os algoritmos foram implementados pela equipe. A leitura do teclado usa recursos basicos da linguagem Java.

COMO EXECUTAR
Compile os arquivos da pasta src mantendo a estrutura de pacotes. A classe principal e Main.java, no pacote ed2.projeto.algoritmosordenacao.

OBSERVACAO SOBRE ARQUIVO TXT
A leitura de numeros de arquivo TXT foi mencionada como opcional no enunciado e nao foi incluída nesta versao, para manter o projeto sem imports e sem classes de leitura de arquivos.
