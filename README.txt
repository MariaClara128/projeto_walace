Projeto de Estrutura de Dados II
Projeto desenvolvido em equipe para a disciplina de Estrutura de Dados II, utilizando Java e python

O trabalho está dividido em duas partes:

1. Algoritmos de Ordenação
Implementação e análise de cinco algoritmos:

Bubble Sort
Insertion Sort
Selection Sort
Merge Sort
Quick Sort
Funcionalidades:

Entrada manual de números;
Geração de números aleatórios;
Leitura de arquivos TXT;
Escolha do algoritmo de ordenação;
Exibição dos dados de entrada e saída;
Comparação do tempo de execução.
Também são realizadas simulações para entradas de tamanho n, n², n³ e n¹⁰, com registro dos tempos estimados em uma tabela comparativa.

2. Tabela Hash
Implementação de uma estrutura de dados utilizando Tabela Hash, conforme as orientações do material disponibilizado pelo professor.

Tecnologias utilizadas
Java;
Python;
IDE de desenvolvimento Java;
Estruturas de dados e algoritmos.
